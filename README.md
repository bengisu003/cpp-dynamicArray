# C++ Dynamic Array OOP Project
Custom dynamic array structures implemented in C++ using Object-Oriented Programming principles without STL containers.

# Project Structure
DynamicArrayProject/
│
├── src/
│   ├── DynamicArray.cpp     — base dynamic array implementation
│   ├── DynamicArray.h       
│   ├── SortedArray.cpp      — automatically sorted array
│   ├── SortedArray.h
│   ├── UniqueArray.cpp      — prevents duplicate elements
│   ├── UniqueArray.h
│   └── main.cpp             — test usage
│
├── ProjectOOP.sln
├── ProjectOOP.vcxproj
├── README.md

# Technologies
- C++
- Object-Oriented Programming
- Visual Studio
